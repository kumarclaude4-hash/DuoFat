VULNERABILITY: WORKER_SECRET is read from local.properties (written by the CI workflow
per SC-02) and compiled into BuildConfig.WORKER_SECRET. The APK's DEX contains the
literal secret value. Any user who extracts the APK (trivially, via GitHub Releases)
can recover the secret and make direct authenticated requests to the Worker, bypassing
per-object capability token authorization.

The Worker /stats endpoint also accepts this secret directly (S08-H1), exposing
global storage usage and request-count metrics to any APK holder.
